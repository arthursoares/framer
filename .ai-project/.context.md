## Common Commands

### Development
```bash
swift build                    # Build all targets
swift run framer               # Run CLI
swift test                     # Run all tests
xcodegen generate              # Regenerate Xcode project
```

### Testing
```bash
# Run all tests
swift test

# Run specific test class
swift test --filter BorderRendererTests

# Run specific test method
swift test --filter test_solidBorder_increasesCanvasSize
```

### Quality Checks
```bash
swift build                    # Type checking via compilation
swift test                     # Full test suite (102 tests)
```

## Error Patterns

### Common Issues

| Error | Cause | Solution |
|-------|-------|----------|
| `Cannot find module 'FramerCore'` | Build not run | Run `swift build` |
| Xcode project stale | Source files changed | Run `xcodegen generate` |
| LFS files missing | LFS not installed | Run `git lfs install && git lfs pull` |
