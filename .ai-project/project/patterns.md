## Naming Conventions

| Type | Convention | Example |
|------|------------|---------|
| Package | lowercase, single word | `main` |
| Public types | PascalCase | `ProcessingConfig`, `ExifData` |
| Private types | camelCase (unexported) | `imageJob` |
| Public functions | PascalCase | `ProcessImage`, `LoadConfig` |
| Private functions | camelCase | `parseColor`, `loadFont` |
| Constants | PascalCase (public) or camelCase (private) | `DefaultQuality`, `maxWorkers` |
| Test functions | `Test` prefix + PascalCase | `TestProcessImage` |
| Benchmark functions | `Benchmark` prefix + PascalCase | `BenchmarkProcessImage` |

## Test Template

```go
func TestFunction(t *testing.T) {
    tests := []struct {
        name     string
        input    InputType
        expected ExpectedType
        wantErr  bool
    }{
        {"valid input", validInput, expectedOutput, false},
        {"invalid input", invalidInput, nil, true},
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            got, err := Function(tt.input)
            if (err != nil) != tt.wantErr {
                t.Errorf("error = %v, wantErr %v", err, tt.wantErr)
                return
            }
            if !tt.wantErr && got != tt.expected {
                t.Errorf("got %v, want %v", got, tt.expected)
            }
        })
    }
}
```

## Common Patterns

### Error Handling
```go
// Return errors with context
if err != nil {
    return fmt.Errorf("opening image %s: %w", path, err)
}

// Defer cleanup
file, err := os.Open(path)
if err != nil {
    return nil, err
}
defer file.Close()
```

### Concurrent Operations
```go
// Worker pool pattern
jobs := make(chan string, len(files))
results := make(chan ProcessingResult, len(files))

var wg sync.WaitGroup
for i := 0; i < workers; i++ {
    wg.Add(1)
    go func() {
        defer wg.Done()
        for path := range jobs {
            results <- processFile(path)
        }
    }()
}

// Send jobs and collect results
for _, f := range files {
    jobs <- f
}
close(jobs)
wg.Wait()
close(results)
```

### Configuration with Defaults
```go
// Use flag package for CLI with defaults

flag.Parse()
```

## Anti-Patterns to Avoid

1. **Don't panic in library code** - Return errors instead
2. **Don't use global mutable state** - Pass configuration explicitly
3. **Don't ignore errors** - Always handle or propagate them
4. **Don't use `any` type** - Use proper types or generics
5. **Don't forget defer cleanup** - Always close files, connections
6. **Don't log in library functions** - Let caller decide on logging
