## Code Organization

The project uses a **single-package architecture** with all Go code in the project root:

- **framer.go**: Contains all application logic:
  - CLI flag parsing
  - Configuration handling (CLI + YAML)
  - Image processing pipeline
  - EXIF metadata extraction
  - Text/caption rendering
  - Frame and border generation
  - Batch processing with concurrency

- **fonts.go**: Contains embedded TrueType fonts as byte arrays (generated)

- **Test files**: Follow Go conventions with `_test.go` suffix, organized by functionality
