> **Generated by:** `/init` workflow

## Development

| Task | Command |
|------|---------|
| Run application | `go run .` |
| Build binary | `go build` |
| Build with name | `go build -o framer .` |

## Quality Checks

| Task | Command |
|------|---------|
| Static analysis | `go vet ./...` |
| Check formatting | `gofmt -s -l .` |
| Fix formatting | `gofmt -s -w .` |
| Tidy modules | `go mod tidy` |

## Testing

| Task | Command |
|------|---------|
| Run all tests | `go test -v ./...` |
| Run single test | `go test -v -run TestName ./...` |
| Run by pattern | `go test -v -run "Pattern" ./...` |
| With race detector | `go test -v -race ./...` |
| With coverage | `go test -v -coverprofile=coverage.txt -covermode=atomic ./...` |
| Run benchmarks | `go test -bench=. ./...` |

## Quick Reference

```bash
# Full validation before commit
go vet ./... && gofmt -s -l . && go test -v -race ./...

# Quick check during development
go vet ./... && go build
```

## Cross-Compilation

```bash
# Darwin ARM64 (Apple Silicon)
GOOS=darwin GOARCH=arm64 go build -o framer-darwin-arm64 .

# Linux AMD64
GOOS=linux GOARCH=amd64 go build -o framer-linux-amd64 .

# Linux ARM64
GOOS=linux GOARCH=arm64 go build -o framer-linux-arm64 .

# Windows AMD64
GOOS=windows GOARCH=amd64 go build -o framer-windows-amd64.exe .
```
