## Project Overview

**Name:** `framer`
**Type:** macOS App + CLI (Image Processing Tool)
**Purpose:** Adds customizable frames, borders, texture overlays, and EXIF-based captions to photos

### Technology Stack

- **Language:** Swift 5.10
- **Platforms:** macOS 14+
- **Package Manager:** Swift Package Manager
- **Xcode Project:** XcodeGen (`project.yml`)
- **Testing:** XCTest (102 tests)

### Key Dependencies

| Package | Purpose |
|---------|---------|
| `swift-argument-parser` | CLI argument parsing |
| `Yams` | YAML configuration/preset parsing |

## Project Structure

```
framer/
├── Package.swift              # SPM package definition
├── project.yml                # XcodeGen project config
├── Framer.xcodeproj/          # Generated Xcode project
├── Sources/
│   ├── FramerCore/            # Image processing library
│   │   ├── Models/            # ProcessingConfig, ExifData, Preset, CompositionLayer
│   │   ├── Processing/        # FrameProcessor, BorderRenderer, CaptionRenderer, ColorExtractor, TextureFrameProvider
│   │   ├── EXIF/              # EXIFReader, MetadataWriter
│   │   └── Presets/           # PresetStore, YAMLConfig
│   ├── FramerCLI/             # Command-line interface
│   │   └── Commands/          # ProcessCommand, PresetsCommand, FontsCommand
│   └── FramerApp/             # SwiftUI macOS application
│       ├── App/               # AppState, FramerApp, FramerCommands, PreferencesView
│       ├── Editor/            # PreviewViewModel, SettingsPanel, LivePreviewPanel, LayerListSection
│       ├── Library/           # PhotoThumbnailView, LibrarySidebar
│       ├── Presets/           # PresetManagerView
│       └── Queue/             # ExportQueueView
├── Tests/
│   └── FramerCoreTests/       # Unit tests with Resources/
├── assets/
│   └── textures/              # Overlay textures (via Git LFS)
├── docs/                      # Documentation
├── .ai-project/               # Project-specific AI config
└── .gitattributes             # LFS tracking rules
```

## Architecture Decisions

See [decisions/](./decisions/) for Architecture Decision Records.

| Decision | Date | Reasoning |
|----------|------|-----------|
| Swift Package with 3 targets | 2026-02 | Separation of core library, CLI, and GUI |
| Layer-based composition | 2026-02 | Flexible pipeline: canvas, border, orientation, caption, overlay |
| Git LFS for textures | 2026-02 | 338MB of overlay images kept out of git objects |
| XcodeGen for project | 2026-02 | Reproducible Xcode project from `project.yml` |
