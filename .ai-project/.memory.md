## Project Overview

**Name:** `framer`
**Type:** CLI Application (Image Processing Tool)
**Purpose:** Adds customizable frames, borders, and EXIF-based captions to photos for Instagram and printing

### Technology Stack

- **Language:** Go 1.22
- **Module:** `github.com/arthursoares/framer`
- **Build System:** Go build tools
- **Package Manager:** Go Modules
- **Testing:** Go testing (built-in)

### Key Dependencies

| Package | Purpose |
|---------|---------|
| `disintegration/imaging` | Image manipulation (resize, crop, transform) |
| `golang/freetype` | TrueType font rendering |
| `rwcarlsen/goexif` | EXIF metadata extraction |
| `schollz/progressbar` | CLI progress indicators |
| `gopkg.in/yaml.v3` | YAML configuration parsing |

## Project Structure

```
framer/
├── framer.go              # Main application entry and processing logic
├── fonts.go               # Embedded font data
├── *_test.go              # Test files (co-located)
├── testdata/              # Test fixtures and sample images
├── fonts_data/            # Font source files
├── examples/              # Example usage
├── docs/                  # Documentation

```

See [decisions/](./decisions/) for Architecture Decision Records.

| Decision | Date | Reasoning |
|----------|------|-----------|
| Single-file architecture | - | Simple CLI tool, all logic in framer.go |
| Embedded fonts | - | Self-contained binary, no external dependencies |
| YAML config support | - | Allow preset configurations for different use cases |
