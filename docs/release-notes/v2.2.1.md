# v2.2.1 — Custom crops and keyboard navigation

This patch release improves editing on macOS and iOS while preserving existing
presets and effect rendering.

## Fixes

- Choosing Custom in an Aspect Ratio layer exposes Width and Height on both
  editors without changing the current crop. The selection survives layer
  collapse, Undo, and preset save/load. Parameter edits preserve layer visibility.
- Left and Right arrows navigate photos from focused macOS filmstrip thumbnails.
  Selection and focus remain synchronized after menu navigation, multi-selection
  collapses to the selected photo, and navigation stops at library boundaries.
  Space continues to toggle Before/After.

## Documentation

GitHub Pages now showcases the native editors, finished sample photos, and
downloadable effect recipes with updated installation instructions.

## Installation and compatibility

Download `framer-v2.2.1-macos-arm64.tar.gz` and `SHA256SUMS`, then run:

```bash
shasum -a 256 -c SHA256SUMS
tar -xzf framer-v2.2.1-macos-arm64.tar.gz
./framer --version
```

Keep `framer` and `framer_FramerCore.bundle` together. The CLI is unsigned and
requires Apple Silicon and macOS 14 or later. Overlay textures remain separate
source/LFS assets. Native apps can be built from source; this CLI archive is not
an app installer. The iOS deployment target remains iOS 17 or later.

Existing presets remain readable. Older aspect-ratio layers default to their
existing editor behavior.
