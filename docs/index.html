Features

Everything you need to add professional borders and metadata captions to your photos.

🎨 Border Styles

Choose from solid, instagram (4:5), print10x15, or vintage styles. Each optimized for different use cases.

📷 EXIF Captions

Automatically extract date, camera, lens, and exposure info from your photos for dynamic captions.

⚡ Batch Processing

Process hundreds of images efficiently with multi-core worker pools and progress tracking.

⚙️ YAML Config

Save complex configurations in YAML files. Auto-loads .framer.yaml from your project directory.

🏷️ Metadata Tagging

Automatically adds IPTC keywords and XMP metadata to processed images for better organization.

🎯 Presets

Built-in presets for vintage, instagram, and minimal styles. Create your own custom presets.

Installation

Get started with framer in seconds.

Homebrew (macOS)

# Add tap and install
brew tap arthursoares/framer
brew install framer

# Update to latest version
brew upgrade framer

Binary Download

Download from Releases:

# Make executable (Linux/macOS)
chmod +x framer-*
sudo mv framer-* /usr/local/bin/framer

From Source

Requires Go 1.22+

# Clone and build
git clone https://github.com/arthursoares/framer.git
cd framer
go build framer.go fonts.go

Usage

Simple commands for powerful photo processing.

Basic Commands

# Process a single image
framer -i photo.jpg -o output/

# Process an entire folder
framer -i photos/ -o output/

# Use a preset
framer -i photo.jpg -o output/ --preset vintage

# Instagram format
framer -i photo.jpg -o output/ -s instagram

Custom Captions

# Camera and exposure info
framer -i photo.jpg -o output/ \
  --caption-template "{{camera}} - {{iso}} {{aperture}} {{shutter}}"

# Date format
framer -i photo.jpg -o output/ \
  --caption-template "{{mon}} '{{year2}}"

# Disable caption
framer -i photo.jpg -o output/ --no-caption
Available Template Placeholders

Date/Time

  • {{year}} - Full year (2024)
  • {{year2}} - Short year (24)
  • {{month}} - Month name
  • {{mon}} - Short month (JAN)
  • {{day}} - Day number
  • {{date}} - Full date

Camera

  • {{camera}} - Camera model
  • {{lens}} - Lens name

Exposure

  • {{iso}} - ISO value
  • {{aperture}} - f-stop
  • {{shutter}} - Shutter speed
  • {{focal}} - Focal length
Configuration File Example

Create a .framer.yaml file in your project directory:

# .framer.yaml
border_style: solid
border_thickness: "5%"
border_color: "#000000"
padding: "150"

# Caption settings
caption_template: " - {{mon}} '{{year2}} -"
font_name: CourierPrime-Bold
font_size: "50"
font_color: "#FFFFFF"

# Output settings
output_format: jpeg
jpeg_quality: 100
All Command-line Arguments 
# Required
--input, -i           Path to image file or directory
--output, -o          Output directory

# Border Style
--border-style, -s    solid | instagram | print10x15 (default: solid)
--border-thickness,-t Thickness in pixels or % (e.g., "20" or "5%")
--border-color        Hex color (default: #000000)
--padding             Padding in pixels (default: 150)

# Caption
--caption             Override caption with custom text
--caption-template    Template with {{placeholders}}
--no-caption          Disable caption entirely
--font-name           Font name (use --list-fonts to see options)
--font-size           Font size in pixels (auto-calculated if omitted)
--font-color          Hex color (default: #000000)

# Print 10x15 Specific
--background-color    Background color for print10x15 (default: #FFFFFF)
--outer-padding       Outer padding from image to edge
--caption-padding     Padding between caption and image

# Output
--output-format, -f   jpeg | png (default: jpeg)
--quality, -q         JPEG quality 60-100 (default: 100)
--no-metadata         Skip adding EXIF metadata to output

# Configuration
--config              Path to YAML config file
--preset              Load preset (vintage, instagram, minimal)

# Performance
--workers, -w         Concurrent workers (default: CPU cores)

# Utility
--list-fonts          Show available fonts and exit
